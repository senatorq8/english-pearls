Install it like an app

  • iPad / iPhone (Safari): tap Share, then “Add to Home Screen”.
  • Android (Chrome): menu ⋮, then “Install app”.
  • Computer (Chrome or Edge): click the install icon in the address bar.

After the first visit, the books open without internet. Progress is saved on each device; no account is needed.
